## Assignment Description

This repository contains the Cisco Packet Tracer files developed for the Computer Networks routing assignment.

## Files Included

### 1sttask.pkt
Task 1 – Basic Router Configuration

Description:
Configured the router hostname, console password, login authentication, and saved the running configuration.

### 2ndtask.pkt
Task 2 – Static Routing

Description:
Configured IP addressing and static routing between three routers. Connectivity between networks was verified using routing tables and ping tests.

### 3rdtask.pkt
Task 3 – Dynamic Routing (RIP and EIGRP)

Description:
Configured RIP Version 2 and EIGRP routing protocols. Dynamic route exchange and end-to-end connectivity were verified successfully.
